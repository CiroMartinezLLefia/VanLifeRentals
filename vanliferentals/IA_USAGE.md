# Uso de IA y registro

Este proyecto ha sido desarrollado con asistencia responsable de herramientas de IA para acelerar tareas repetitivas y generar plantillas de código. A efectos de evaluación, se documenta lo siguiente:

- Herramientas: Asistencia de LLM para generación de boilerplate y sugerencias de tests (registro interno del autor).
- Prompts principales (resumidos):
  - "Genera tests Playwright básicos que verifiquen los endpoints /api/models, /api/models/:id/comments y /api/contact para una app Next.js con Prisma seed." 
  - "Crea un README con instrucciones de despliegue y credenciales de prueba para QA." 

- Revisión humana: todo código generado fue revisado y adaptado manualmente para asegurar coherencia, validación y evitar fugas de datos.

Si el profesorado requiere, se podrá adjuntar el historial completo de prompts y las respuestas (exportadas) para auditoría.
